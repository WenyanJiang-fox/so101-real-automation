## 两趟的实测数（都在 `logs/` 里）

| | 第一趟（终点 −1mm） | 第二趟（终点 +2mm） |
|---|---|---|
| 画面量的中心 z | −14.0mm | −14.0mm |
| 竖直下探指令 | 中心 −1mm = −15.0mm | 中心 +2mm = −12.0mm |
| 实际读回 | **−17.9mm**（多走 2.9mm） | **−16.4mm**（多走 4.4mm） |
| 水平漂移 | 8.9mm | 9.3mm |
| 验收 | z 差 2.9 ≤ 10、横漂 8.9 ≤ 20 → 认 | z 差 4.4 ≤ 10、横漂 9.3 ≤ 20 → 认 |
| 合爪 | +1.735 → −0.018 rad，判 held | +1.735 → −0.023 rad，判 held |
| 结果 | `ok: True`，放件 (240, 43)mm | 放件 (249, 99)mm |

第一趟用户看到爪尖戳到桌面；第二趟用户判「挺完美的」。

**注意：** 两趟竖直那一下都比指令多走了 2.9 / 4.4mm（`_descend_to_grasp` 只解一趟、
不重解，受重力影响）。验收阈值是 `DESCEND_Z_TOL_MM = 10.0`、`DESCEND_XY_TOL_MM = 20.0`，
这两趟都在窗口内被放过。下一次要更稳，先动这两条阈值或让那一截多解一趟，别只抬终点。
